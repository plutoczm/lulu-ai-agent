# 噜噜品牌规范

## 品牌定义

- 中文名：噜噜
- 英文副标：LULU AI
- 项目名：lulu-ai-agent
- 品牌角色：水豚噜噜
- 定位：温暖、可靠、松弛但聪明的个人 AI 助手
- 核心产品：AI 对话军师 / AI 超级智能体

噜噜不是冷冰冰的企业机器人，也不是低幼萌宠。
它应该像一只很稳的水豚：情绪稳定、愿意陪伴、做事靠谱，
在需要处理复杂任务时又能体现明确的 AI 能力与专业感。

## 视觉方向

- 主橘：#F28C28
- 杏黄：#FFB347
- 深橘：#E9711C
- 奶油白：#FFF8EF
- 浅杏：#FFF1DE
- 焦糖棕：#5A3A22
- 正文深棕：#35271D

辅助状态色可以保留绿色、红色等语义色，但避免重新出现大面积蓝紫主视觉。

## 水豚噜噜角色原则

- 以“水豚噜噜 / CapyLulu”现有 IP 形象为角色参考，不再设计成普通棕色水豚
- 主体为明亮金黄色，身体圆润、软糯，整体采用高质量治愈系 3D 造型
- 口鼻区域是最明显的大面积橙色渐变，是核心识别特征
- 头顶固定一颗小橘子，不能改成围巾、帽子或其他水果
- 大而圆的黑色眼睛带明显白色高光，小耳朵，嘴部简洁
- 常规全身造型搭配橙色短裤；不要额外加入围巾、复杂服装或机械配件
- 气质是呆萌、情绪稳定、松弛、治愈，同时在产品场景里保持可靠感
- 保留原角色的柔软 3D 光照和圆润材质，但避免廉价塑料玩具质感
- 角色参考素材统一放在 design/references/lulu/，正式发布素材需确认 IP 授权范围

## UI 原则

- 大面积奶油白背景，卡片使用白色或浅杏色
- CTA 使用蜜橘到杏黄渐变
- 深色文字使用焦糖棕而不是蓝黑
- 边框使用低对比暖灰 / 米色
- 圆角适度，保持 B 端产品的信息密度
- 插图负责亲和力，界面结构保持专业和清晰
